# Incident Library Route

This route presents documented cross-chain and reward-accounting failures without overstating Minos's protection. Each expandable record separates the reported incident, the Minos-owned destination control, and the boundary where the original protocol still requires its own fix.

To find the incident-library interface and accessible FAQ controls, visit [+page.svelte](file:///C:/Hackathons/Proof%20Firewall/src/routes/problems/+page.svelte).

The incident records and their primary-source links can be found in [problem-records.js](file:///C:/Hackathons/Proof%20Firewall/src/lib/problem-records.js).
