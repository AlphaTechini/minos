# Loan Policy

This directory contains the constrained policy compiler and machine-readable schema for the first ProofGuard loan policy. The compiler deliberately supports one fixed event model instead of a general-purpose policy language.

To find deterministic policy normalization, rule hashing, and policy identity generation, visit [compiler.mjs](file:///C:/Hackathons/Proof%20Firewall/policy/compiler.mjs).

The policy manifest schema can be found in [loan-policy.schema.json](file:///C:/Hackathons/Proof%20Firewall/policy/loan-policy.schema.json).
